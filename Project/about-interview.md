# Journey Map
### First (จุดเริ่มต้นก่อนเข้างาน / เริ่มต้นวัน)
ความรู้สึก: รู้สึกแจ่มใส มีแรงจูงใจในการทำงาน มุ่งมั่นพร้อมให้บริการลูกค้า และรู้สึกดีต่อบรรยากาศในสถานที่ทำงานและเพื่อนร่วมงาน  
การกระทำ: เดินทางมาทำงานที่ห้างสรรพสินค้าเซ็นทรัลพระราม 2 พร้อมรับหน้าที่ตามจุดบริการของตนเอง (เช่น ชงชา/รับออเดอร์, ขายตั๋ว/ป๊อปคอร์น, ขายโน้ตบุ๊ก/ไอที)  
### Next (ระหว่างปฏิบัติงานในร้าน - จุดพีกและจุดดรอป)

#### จุดพีก (Positive)

```
    ได้รับพลังบวกจากบรรยากาศการทำงาน และความน่ารัก เป็นกันเอง มีอัธยาศัยที่ดีของเพื่อนร่วมงาน ได้ใช้ความรู้และทักษะความเชี่ยวชาญเฉพาะทางในการดูแล ช่วยเหลือ และแก้ปัญหาให้ลูกค้าอย่างรวดเร็ว (Take Action)  เกิดความภาคภูมิใจเมื่อเห็นร้านค้า/ศูนย์การค้าคึกคักและมีลูกค้าเข้ามาใช้บริการจำนวนมาก โดยเฉพาะในช่วงวันหยุด เสาร์-อาทิตย์ วันหยุดนักขัตฤกษ์ หรือช่วงที่มีภาพยนตร์เรื่องใหม่เข้าฉาย 
```
#### จุดดรอป (Negative)
```
    ปัญหาด้านการบริหารจัดการและการบริการ: พบช่วงเวลาที่ลูกค้าน้อย/ขายไม่ค่อยได้, ปัญหาการคาดเดาปริมาณสินค้ายาก (เช่น ป๊อปคอร์นไม่พอขาย หรือทำไว้เยอะแล้วขายไม่ออก), การรันคิวไม่ทันเมื่อมีปริมาณลูกค้าหนาแน่นมาก  
ปัญหาขอบเขตความช่วยเหลือและโครงสร้างพื้นฐาน: ลูกค้านำสินค้าหมดประกัน/ชำรุดหนักมาให้ช่วยซ่อมซึ่งประสานงานยาก, ปัญหารั่วซึมของอาคาร (น้ำหยดเวลาฝนตก) บริเวณหน้าร้าน จนลูกค้า Complain และเกรงว่าจะเกิดอุบัติเหตุลื่นล้ม 
``` 
### Then (หลังปฏิบัติงานเสร็จ / จบวัน)
    ความรู้สึก: รู้สึกผ่อนคลายและสบายใจเมื่อสามารถแก้ไขปัญหาเฉพาะหน้าให้ลูกค้าสำเร็จ แม้จะเหน็ดเหนื่อยจากอุปสรรคและปริมาณงาน แต่ยังมีกำลังใจจากการมีสภาพแวดล้อมการทำงานและสังคมเพื่อนร่วมงานที่ดี พร้อมที่จะกลับมาปฏิบัติงานและส่งมอบบริการที่ดีในวันถัดไป  
 # Empathy Map (Say - Think - Do - Feel)
1. โดนัท (อายุ ~20s) | พนักงานขายร้าน OWL
 * Think (คิด): กังวลเรื่องยอดขายเพราะลูกค้าน้อย ตระหนักว่าถ้าเกิดข้อผิดพลาดต้องรีบแก้ไขให้ลูกค้าทันที
 * Feel (รู้สึก): เหงาหรือเบื่อช่วงวันธรรมดา แต่มีความสุขและสบายใจเพราะชอบเพื่อนร่วมงาน
 * Say (พูด): พูดคุยสอบถามออเดอร์กับลูกค้าอย่างสุภาพ และโทรศัพท์พูดคุยกับลูกค้าอย่างแสดงความรับผิดชอบเมื่อเกิดปัญหา
 * Do (ทำ): รับออเดอร์ ชงชาตามคำสั่งซื้อ และยกหูโทรศัพท์ติดต่อลูกค้าเพื่อแก้ไขปัญหาทันที

# Point Of View (POV) Statement
#### We met (เราได้พบกับ)
พนักงานขายและบุคลากรหน้าร้านในเซ็นทรัลพระราม 2 ที่มุ่งมั่นให้บริการ ดำเนินงานในร้านให้ราบรื่น และพร้อมเข้าช่วยเหลือเมื่อลูกค้าเกิดปัญหา  
#### We were surprised to notice (เราประหลาดใจที่สังเกตเห็นว่า) 
แม้เป้าหมายหลักของพวกเขาคือการทำยอดขายและให้บริการตามหน้าที่ แต่สิ่งที่สร้างความกังวลและฉุดประสิทธิภาพการทำงานมากที่สุด กลับเป็น "ปัจจัยภายนอกที่ควบคุมยาก" เช่น ปัญหาสินค้าหมดประกันที่ประสานงานซ่อมลำบาก ปริมาณลูกค้าที่หนาแน่นจนรันคิวและสินค้าไม่ทัน รวมถึงปัญหาโครงสร้างอาคารชำรุด (น้ำรั่วซึม)  
#### We wonder if this means (เราสงสัยว่าสิ่งนี้หมายความว่า)
หน้าร้านไม่ได้เป็นเพียง "จุดขายสินค้า" แต่ทำหน้าที่เป็น "ปราการหน้าด่านในการรับแรงกระแทกจากปัญหา" ซึ่งพนักงานต้องรับภาระทั้งการแก้ไขปัญหาทางเทคนิค ปัญหาสภาพแวดล้อม และอารมณ์ของลูกค้า โดยมีเพียง "บรรยากาศเพื่อนร่วมงานที่ดี" เป็นสิ่งยึดเหนี่ยวจิตใจ  
#### It would be game-changing to (มันจะเป็นการพลิกเกมเลยถ้าเราสามารถ)
พัฒนาระบบสนับสนุนการจัดการหน้าร้านและการส่งต่อเคสซ่อม/เคลมสินค้าให้รวดเร็วและมีมาตรฐาน ชัดเจน ควบคู่ไปกับการปรับปรุงดูแลโครงสร้างพื้นฐานของพื้นที่ให้ปลอดภัย เพื่อลดภาระงานซ้ำซ้อนและลดความกังวลของพนักงาน ทำให้พวกเขาสามารถโฟกัสกับการส่งมอบบริการและสร้างบรรยากาศที่ดีให้กับลูกค้าได้อย่างเต็มที่
